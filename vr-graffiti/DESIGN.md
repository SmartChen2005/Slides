# VR Graffiti presentation

This is an English concept presentation for an XR learning course, using the
repository's existing static HTML deck pattern and uniformly scaled 1280 × 720
canvas. The archive retains its own root design system.

The slide-specific canonical tokens live in `styles.css :root`. Paper is
`#fafaf8`, ink `#202321`, muted text `#636863`, rules `#d9ddd7`, and teaching
green `#276b4a`. Purple and ochre appear only in creative marks or deviation
diagrams. Helvetica/Arial carries the titles and body. Courier labels numerical
timing and phases. No font requests or external runtime dependencies.

The signature is the recorded S gesture: a wall mark, its tool trajectory,
then a time-indexed spatial line. Motion illustrates interaction rather than
decorating slide transitions. Native editable SVG diagrams make the concept
explicit without implying a working VR application. Flat compositions and
large typography follow the supplied keynote direction.

The first 11 slides have a planned running time of 7:30. References and Q&A are
backups. All references are clickable and also appear with presenter notes.
No presentation date or semester deadline is inferred from file timestamps.

Controls follow the sibling deck: previous/next, keyboard arrows, URL hashes,
inert inactive slides and uniform scaling. Added canonical deck actions are
Notes (N), Replay (R), Pause (Space), and Full screen (F). End opens the final
timed slide. Next then opens reference and Q&A backups. Notes are a labelled
non-modal reading pane with explicit close, Escape and focus restoration.

Reduced motion starts with paused explanatory frames. Replay/Play explicitly
opts into motion. Hidden browser tabs suspend animation. Print shows all
slides with deterministic illustrative frames, without presenter controls.
The self-contained HTML export also works offline. Its Archive link is hidden
because the containing archive is absent.
